# 爱乃首次飞行 · 插入式小游戏

使用原游戏 SiglusEngine 和现有 SS、驾驶舱图、音效与角色语音，通过 SSSU 编译。

## 进入方式

正常推进爱乃线 8 月 13 日首次飞行，在起飞后「だったら俺も、腹を決めよう。」之后选择是否游玩。
选择跳过继续原剧本；成功着陆并确认结算后直接进入「……着陸成功だ。」。
失败可重试，也可退出小游戏继续原剧本，成绩不改变路线或剧情结局。

## 操作

| 按键 | 功能 |
| --- | --- |
| Enter | 开始、恢复、成功结算后继续；失败时重飞；退出确认时取消 |
| ↑ / ↓ | 压机头 / 拉机头；按住改变俯仰，松开保持姿态 |
| ← / → | 左右滚转；松开后机翼缓慢自动回平；在地面控制方向（静止时很慢，约 20 kt 以上最灵敏） |
| Q / A | 按住线性增减油门，每秒 25%；松开保持，范围 0–100% |
| B | 接地后按住刹车；接地前无效 |
| P / Esc | 飞行时只暂停；菜单 Esc 打开退出确认 |
| R | 暂停或结算时重飞 |
| 鼠标菜单 | 点击按钮操作菜单，退出须再次确认 |

### 手柄

括号内为 PlayStation 手柄上的对应按键。

| 手柄 | 功能 |
| --- | --- |
| 左摇杆 / 十字键 | 同 ↑↓←→：俯仰、滚转，在地面控制方向 |
| RT / LT（R2 / L2）或右摇杆上下 | 同 Q / A：增减油门 |
| B（○） | 飞行中同 B 键：接地后按住刹车 |
| START（OPTIONS）/ BACK（Create） | 飞行中暂停 |
| 菜单中 ← / → | 在按钮之间移动高亮 |
| A（×） | 按下高亮的按钮 |
| START（OPTIONS） | 简报时开始飞行；暂停时继续 |
| B（○） | 暂停时继续；简报和失败界面打开退出确认；退出确认时取消 |
| Y（△） | 暂停、结算、失败时重新起飞 |
| BACK（Create） | 菜单中同 Esc：打开退出确认；退出确认时取消 |

- 按下手柄任意键后，画面下方的按键提示和菜单说明换成手柄按键名称；移动鼠标或按键盘键后换回。
- 退出确认中必须把高亮移到「确认退出」再按 A，其他按键都是取消。
- 结束小游戏时，等手柄按钮全部松开才回到剧情，刚才按下的 A 不会让剧情跳过一句。
- 引擎只读取 XInput（Xbox 规格）手柄。PS5 DualSense、PS4 等手柄需要通过 Steam 输入（把 `SiglusEngine.exe` 添加为非 Steam 游戏并从 Steam 启动）或 DS4Windows 转换后使用。

## 飞行与评分

满油门滑跑，约 47 kt 起按住 ↓ 抬头 8–10° 并保持，约 49 kt 时升力超过重量自然离地；按空中引导框完成左五边，再降落同一跑道。
满油门爬升约 600–700 fpm（55–60 kt）。巡航高度约 150 m（约 490 ft）、约 58 kt、油门约 55%；转弯时升力有一部分用来转向，需轻拉 ↓ 补足才能保持高度。
四边油门 30–40%、52–56 kt；五边油门 20–30%、52–55 kt，瞄准跑道入口后 220 m 处的橙色十字（瞄准点）。接近地面时轻拉机头拉平，地面效应会让飞机飘一段；接地后 A 收油门、按住 B 刹车（从 48 kt 约 80 m 停住，不刹车约 290 m）。

19 个引导框按顺序计分，越接近中心分越高。漏框得零分并继续，重复或反向穿框不加分。最后一个航线点是跑道上的瞄准点，不再需要穿过。
总分 100：引导框 50、接地轻柔 30（90 fpm 以内满分，900 fpm 为 0）、中线 10（偏离 0.5 m 以内满分，8 m 为 0）、瞄准点 10（沿跑道前后 5 m 以内满分，75 m 为 0，偏早偏晚同样计算）。
首次接地时锁定下降率、偏离中线的距离和距瞄准点的距离；接地后画面上方短暂显示「中线 偏左 x.x m · 瞄准点 偏早/偏晚 x.x m」，结算页逐项列出。
通过第 19 框（跑道入口）并完成左五边后，在跑道内以合理速度和姿态着陆并停稳即为成功，在瞄准点之前接地也算成功。越界、失速导致撞地、严重重着陆或未完成航线会失败。

## 飞行模型

按轻型双翼机的质点气动模型计算，仍为 50 Hz 定步长整数运算：

- 升力和阻力由迎角与动压决定（迎角 = 俯仰 + 3° 机翼安装角 − 航迹角）；阻力含废阻和与升力平方成正比的诱导阻力，全机升阻比约 8.7。
- 迎角约 14.4° 时失速，升力骤降、机头自动下沉。失速速度：机翼水平约 44 kt，30° 坡度约 47 kt，45° 坡度约 52 kt。迎角接近临界时 HUD 显示黄色提示，失速时显示红色警告。
- 转弯率由升力的水平分量决定（g·tanφ/V）；带坡度而不拉杆会掉高度。
- 定距螺旋桨推力随空速下降，收油门时螺旋桨风车阻力使飞机下滑，滑翔比约 7.6:1。
- 方向键控制俯仰与滚转角速度，舵效随动压变化，低速时变软；松开后保持姿态，并带轻微回到约 57 kt 配平迎角的静稳定性。
- 地面滚动摩擦按未被升力承担的重量计算；离地 1 机翼翼展以内有地面效应，诱导阻力减小。
- 为适应键盘操作，地面姿态按机头水平处理，不模拟后三点式尾轮。

## 地标与画面

地标全部从原游戏背景图裁切：风车（BG707）、牧场谷仓与筒仓（BG021）、天文台（BG301）、旧校舍（BG016）、商店街（BG206）、「スイカの町」欢迎牌（BG506）、机库（BG202）、拖车（BG101）和树丛（BG702）。
`tools/prepare_flight_landmarks.py` 用 SSSU 解出原 g00，按轮廓去除画面中的天空，再生成新的 `g00/FL_lm_*.g00`，原文件只读不改。
各地标按航段放在机头前方易见的位置：一边爬升前方是风车（叶片转动），二边朝向海岸，三边前方是牧场，转四边前是天文台，四边朝向小镇。
北侧约 2.4 km 处是海岸线、沙滩、海面和五座转动的风力发电机，对应原剧本「海まで出たら、旋回します」。
地面另有通往小镇和牧场的道路、沿海公路、麦田、波斯菊花田和西瓜田；远处地标带有大气雾化。

HUD：顶栏为航段与引导框进度、通过/漏框数（飞行中不显示引导框得分，得分见结算页）；底部仪表条分格显示空速、高度、离地、航向、油门和垂直速率，接地后改为锁定的接地下降率。
每过一框在画面上方短暂显示「第 N 框 · 通过 / 漏框」；小地图显示海岸、地标、航线和本机。
